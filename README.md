# server-rs

Учебное переписывание `localzet/Server` на Rust без внешних зависимостей.

Сейчас реализовано минимальное TCP-ядро:

- жизненный цикл сервера и управляемая остановка;
- приостановка и возобновление принятия соединений;
- обработчики подключения, сообщения, закрытия и ошибок;
- TCP-соединение с отправкой данных и адресами сторон;
- потокобезопасная статистика соединений и трафика.

Запуск echo-сервера:

```text
cargo run -- 127.0.0.1:8080
```

Это намеренно простая модель «один поток на соединение». Следующий логичный этап — протоколы `Text` и `Frame`, после чего можно выделить event loop без изменения пользовательских обработчиков.
