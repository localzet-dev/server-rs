# server-rs

Экспериментальное продолжение [localzet/Server](https://github.com/localzet/Server) на Rust. Это частичный перенос, совместимость с PHP-библиотекой не заявлена. Общая тема репозиториев — [localzet-server](https://github.com/topics/localzet-server).

[English documentation](README.md)

## Сборка и запуск

Проверенная версия Rust — 1.98+. Используется редакция Rust 2024 и зависимости из `Cargo.toml`; проект уже не является реализацией без зависимостей.

```sh
cargo test --locked --all-targets
cargo clippy --locked --all-targets --all-features -- -D warnings
cargo fmt -- --check
cargo run --locked -- 127.0.0.1:8080
```

Исполняемый файл запускает echo-сервер. Для локальной разработки сохраняйте привязку к loopback.

## Реализованные компоненты

- жизненный цикл TCP-соединений, управляемая остановка, статистика;
- UDP-соединения, отложенные и повторяющиеся таймеры;
- протоколы Text и Frame с префиксом длины;
- разбор HTTP, объекты ответов, кодирование и декодирование Redis;
- рукопожатие и кодек кадров WebSocket;
- файловое хранение сессий и сериализация;
- начальные интерфейсы цикла событий и типы совместимости.

Кодеки сами по себе не образуют законченный HTTP/WebSocket-сервис. Тесты проверяют TCP/UDP, отмену таймеров, отклонение обхода пути сессий, некоторые варианты неоднозначного HTTP framing и примеры протоколов. Они не доказывают полное соответствие стандартам, устойчивость к атакующим данным или производительность под нагрузкой.

## Ограничения и развитие

TCP использует один поток на соединение. Часть платформенных адаптеров разделяет простую реализацию: название не означает поддержку нативного epoll, Swoole или Windows IOCP. Хранилища сессий Redis/MongoDB требуют завершения реализации и проверки с настоящими сервисами. Прототип не готов для публичного production-сервера.

До выпуска нужно определить поддерживаемые подмножества протоколов и лимиты; проверить фрагментацию, объединение пакетов и исчерпание ресурсов; реализовать и измерить цикл событий по готовности дескрипторов; проверить внешние хранилища сессий; стабилизировать API Rust. Где требуется совпадение поведения с PHP, нужны общие сценарии проверки. CI не включает развёртывание и публикацию в crates.io.
